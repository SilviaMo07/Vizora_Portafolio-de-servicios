# Vizora — portafolio de servicios

Sitio institucional responsive para presentar los servicios de Vizora: menús digitales con realidad aumentada, el asistente conversacional Vizi y gestión de contenido gastronómico. Incluye los mensajes clave, el posicionamiento de marca, la misión, la visión 2030 y los valores de Vizora.

Los doce recursos gráficos de `simbolos/` se usan como iconos principales de los cuatro servicios, pasos de la experiencia y beneficios. El nombre del archivo `Nube}.png` se referencia como `Nube%7D.png` en el HTML para codificar correctamente la llave en la URL.

## Abrir el sitio

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. El diseño se adapta a celular, tablet y computador. Las tipografías se cargan desde Google Fonts; el resto de la interfaz y sus interacciones no requiere un framework.

## Contacto

El formulario prepara una consulta dirigida a `innovatemultimedia@gmail.com` mediante `mailto:`. El visitante debe enviarla desde su aplicación de correo. Para envío automático desde el sitio hace falta integrar un servicio de formularios o un backend.
